# 实验结果说明

## 实验配置

| 参数 | 值 |
|------|-----|
| 迷宫大小 | 8×8 |
| 墙壁概率 | 15% |
| 动作噪声 | 15% |
| 多巴胺系数 β | 5.0 |
| 训练轮数 | 800 |
| 基线 ε 衰减 | 0.95（~70轮停止探索） |
| DopAgent ε 衰减 | 0.993（持续探索） |

| 总成功次数 | 0/800 (0%) | 203/800 (25%) |
| 最后100轮成功 | 0/100 | 43/100 |

| 评估最好成绩 | 0/10 | 10/10 |

## 理论映射

| 认知科学概念 | 计算实现 | 数据证据 |
|-------------|----------|---------|
| 奖励预测误差 (RPE) | R_int = MSE(f(s,a), s') | 内在奖赏曲线 |
| 习惯化 (Habituation) | 前向模型训练 → MSE降低 | 内奖0.22→0.05 |
| 内在动机 | β × R_int 驱动探索 | 热力图对比 |
| 多巴胺时相性发放 | 高预测误差 → 高内奖 | DopAgent成功曲线 |
